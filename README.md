# Layout Divs

Projeto desenvolvido para prática de diagramação e posicionamento de elementos em páginas web, utilizando HTML e CSS com foco no uso de Flexbox e estruturação com divs.

## Sobre o Projeto

O repositório reúne uma coleção de 20 layouts numerados mais um layout desafio, explorando diferentes combinações de alinhamento, espaçamento, aninhamento de caixas e distribuição de elementos na tela.

A página principal (`index.html`) funciona como um sumário central de navegação para acessar visualmente cada uma das páginas de layout.

## Estrutura do Repositório

- `index.html`: Página principal com links de navegação para todos os layouts.
- `layout-1.html` a `layout-20.html`: Páginas com diferentes estruturas de diagramação e exercícios de divs.
- `layout-desafio.html`: Exercício avançado integrando múltiplos níveis de aninhamento e posicionamento.
- `style.css`: Folha de estilos central contendo as classes utilitárias e regras de estilização compartilhadas.

## Tecnologias

- HTML5
- CSS3 (Flexbox)

## Como Executar

1. Clone o repositório ou faça o download dos arquivos:
```bash
git clone https://github.com/isabela728/layout-divs.git
```

2. Acesse a pasta do projeto:
```bash
cd layout-divs
```

3. Abra o arquivo `index.html` em qualquer navegador web.
